本番で動いている大規模言語モデル製品

本番で稼働している大規模言語モデル製品『Grow』を、一人で設計・実装・運用している（2026-06 着手・2026-07 から本番運用）。Next.js／TypeScript／Supabase／Anthropic API。1セッションあたりの API 原価を実測している。

Growは毎日の仕事から、今日の結論・明日の一手・自分だけの勝ち筋をつくる壁打ちAIです。

  • 紹介: https://grow-app.jp
  • アプリ: https://app.grow-app.jp

技術構成（package.json の記載のまま・2026-09-11 時点）: next 16.2.9／react 19.2.4／typescript ^5／Supabase（supabase-js ^2.108.2）／Anthropic API（Anthropic TypeScript SDK ^0.106.0）。配信は Vercel。PWA（app/manifest.ts）。

API 原価の実測:

  • 1セッションあたり ¥5.24（無料）／¥13.12（Plus・trial 実測）。2026-07-31・n=3セッション・当時のプラン構成（無料／Plus の区分があった時点の値）。単価は Sonnet 4.6 $3／$15 per MTok・Haiku 4.5 $1／$5・USD/JPY 163.50。

事業課題を技術に落とした記録

事業上の判断を技術に落とした記録を、決定ログとして残している（2026-07 から・500件以上・日付、決定、理由、採用しなかった案）。全文は非公開だが、相談が具体化した相手には個別に開示する。

決定ログは 2026-07-12 から書き始め、2026-09-11 時点で 578 行。1行に日付と1つの決定または記録。理由と、採用しなかった案も同じ形式で残す。

記号（§・行番号）は非公開の正本と実装への参照。抜粋は原文のまま。

Claude Code の実務利用

設計は Claude との壁打ち、実装と検証は Claude Code で行っている。正本を実装セッションに書き換えさせない・1回の改修で入れる変更は1つ・検査は対照で有効性を示す、という運用を続けている。

運用の一周: 壁打ち → タスクプロンプト → Claude Code の実装と検証 → HANDOFF の未裁定 → 検分

  • 公開前の検査スクリプト: https://github.com/neoself1973/grow-mobile/blob/main/scripts/check-demo-build.sh
