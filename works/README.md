## 1. コーポレートサイト（`corporate3/`）

- ブレークポイント **960px**（配布元の指定）
- サイドメニュー 300px 固定、内容幅 900px（内側 860px）
- フォント：Noto Sans JP（Google Fonts・配布元の指定）

実装した挙動：

| 挙動 | 実装 |
|---|---|
| 固定サイドメニュー | `position: fixed` の 300px カラム |
| 固定背景 | `position: fixed` の背景の上を、半透明グラデーションのセクションが流れる |
| 円のホバー | 疑似要素を `translateX(-100%)` から 0 へ。左から右に塗りが入る |
| 問い合わせボックスのホバー | `inset box-shadow` で枠を 3px 相当に。レイアウトは動かさない |
| 家づくりの流れ | 画像を使わず `clip-path` の矢印ブロック＋黄色い帯 |
| ページトップへ戻る | 700px スクロールで表示（配布元の指定どおり） |
| ハンバーガー | 960px 以下で全画面ドロワー。Esc・リンク押下で閉じる |

## 2. WordPress オリジナルテーマ（`akarui-house/`）

静的版と**同じ HTML/CSS を出力する**ようにテンプレート化したもの。

```
akarui-house/
  style.css            テーマヘッダー + 静的版と同一のCSS
  functions.php        テーマサポート／メニュー／カスタマイザー
  inc/post-types.php   カスタム投稿タイプ 2つ
  header.php footer.php
  front-page.php       トップ
  archive-works.php    建築事例一覧（ページネーション付き）
  single-works.php     建築事例 個別
  index.php page.php 404.php
  template-parts/section-{works,features,flow,contact}.php
  js/script.js  img/
```

カスタム投稿タイプ：

| 投稿タイプ | 用途 | 設定 |
|---|---|---|
| `works` | 建築事例 | アーカイブあり・個別ページあり・アイキャッチ・並び順（`menu_order`） |
| `flow` | 家づくりの流れ | 個別ページなし（`publicly_queryable: false`）・並び順で表示 |

- 管理画面の一覧に「写真」「並び順」列を追加。アイキャッチ未設定は赤字で警告
- メニュー3か所（グローバル／SNS／フッター）を `register_nav_menus` で登録。
  未設定でもカンプどおりの並びが出るフォールバックあり
- メインビジュアルの画像はカスタマイザーから差し替え可
- テーマ切り替え時に `flush_rewrite_rules()`（`/works/` の 404 防止）
- 出力は `esc_html` / `esc_url` / `esc_attr` でエスケープ済み

### 確認済みの範囲と、まだ確認していないこと

- **確認済み**：全 PHP ファイルが `php -l` を通ること。
  WordPress の関数をスタブに差し替えて全テンプレートをレンダリングし、
  **静的版と同じ 122 項目の座標チェックを通ること**（差 0）。
- **未確認**：実際の WordPress に入れて動かしていません。
  投稿タイプの登録、パーマリンク、管理画面の表示は実機で一度確認してください。
  ローカル（Local / MAMP など）にテーマを入れて有効化 →
  建築事例を4件・流れを5件登録 → トップと `/works/` を表示、で足ります。

## 3. ランディングページ（`lp/`）

- ブレークポイント **900px**（配布元の指定）
- 内容幅 860px、フォント **游ゴシック**（配布元の指定・OS標準フォント）
- 字送りはカンプの `letterSpacing: 100` = `0.1em`

実装したアニメーション：

| 指示 | 実装 |
|---|---|
| ハンバーガーをフェードで全画面表示 | `opacity` の transition ＋ `hidden` 属性の切り替え |
| メインビジュアル3枚を5〜7秒で切り替え | `@keyframes` で 18 秒周期・1枚6秒のクロスフェード |
| CTAボタンのホバーで少し拡大 | `transform: scale(1.04)` |
| 選ばれる理由：左要素は左から、右要素は右から | `translateX(±60px)` → 0 |
| 受講生の声：小さい状態からふわっと拡大 | `scale(.85)` → 1 ＋ `opacity` |
| 吹き出しはCSSで作り、デバイスで向きを変える | `clip-path` の三角。PC は横向き、SP は下向き |
| ビューポート進入で発火（元指示は jQuery inview） | **IntersectionObserver**（依存ライブラリなし） |

## カンプと指示書が食い違っていた点（実装での判断）

デザインカンプを正として実装し、以下は申し送りにしています。

| # | 内容 | 判断 |
|---|---|---|
| 1 | LP の「背景のドット柄を右上から左下へ流す」 | **実装していない。** カンプの赤帯は単色 `#FF2A2A` 一色（ピクセルを調べて確認）。指示書にはあるがカンプに無い |
| 2 | コーポレートサイトの流れリスト：番号の縦ピッチがカンプで 121 / 128 / 128 / 128 | **128 に統一。** 繰り返しリストの1か所だけ違うのは意図ではないと判断 |
| 3 | 見出しと下の罫線の間隔：カンプ内で 28px（理由）と 24px（声・概要）が混在 | **24px に統一。** 帯の位置はカンプどおりに保つため margin で吸収 |
| 4 | LP 概要カード：カンプの SP は左右余白 33px だが、本文16文字（16px＋0.1em＝281.6px）が 277px に収まらない | **SP のみ余白 30px。** 字送りと3行構成はカンプどおり |
| 5 | LP 概要カードの2行目の左位置がカンプで 720 と 730 に分かれている | **720 に統一**（左右対称になる方） |
| 6 | コーポレートサイトのメインビジュアルは「動画背景」と指示書にあるが、カンプは `#DEDEDE` のベタ | **カンプどおり固定背景の仕組みで実装**し、画像/動画を差し替えられる形にした |

## 画像について

カンプに入っていた建築写真4枚は、配布元が
「画像は当サイトのものではない為、グレー画像に置き換えています」と明記しているため、
**公開版では同じくグレーのプレースホルダーに差し替えています。**
出所の分からない写真を公開ポートフォリオに載せないためです。

LP のアイコン（PC・人物・アバター）は**すべて自作の SVG** に置き換えました。
ロゴ（明るいHOUSE／BBB）はカンプのパスデータから SVG として書き出したものです。

## 検証の方法

座標は目分量で寄せていません。XD ファイル（`.xd` は中身が ZIP + JSON）を
パースして全要素の座標・色・フォントサイズ・行送り・字送りを数値で取り出し、
ヘッドレス Chromium で実装をレンダリングして
`getBoundingClientRect()` と突き合わせています。

| 対象 | 検査項目 | 結果 |
|---|---|---|
| コーポレートサイト 静的版 | 形状 103 / ベースライン 19 | **122 / 122 一致**（許容 ±1px） |
| WordPress テーマの出力 | 同じ 122 項目 | **122 / 122 一致** |
| LP | 形状 106 / ベースライン 35 | **141 / 141 一致**（形状 ±1px・文字 ±3px） |

横方向のチェック（320 / 360 / 375 / 414 / 600 / 768 / 900 / 960 / **1000** /
1024 / 1100 / 1280 / 1400 / 1600 / 1920px）で横スクロール 0 を確認。
**1000px 付近は崩れの報告が最も多い幅**なので必ず入れています。
実際、最初の実装では 961px と 1000px で 133px / 94px の横スクロールが出ていました
（3カラムを 258px 固定にしていたのが原因。可変に直しています）。
